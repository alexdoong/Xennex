# Como publicar no Cloudflare Pages (100% Grátis & Sem Dormir)

1. Entre em https://dash.cloudflare.com/ e vá em Workers & Pages.
2. Clique em "Create application" -> aba "Pages" -> "Upload assets".
3. Dê um nome para o seu projeto (ex: xennex-stream).
4. Arraste esta pasta ("cloudflare_pages") inteira para lá e clique em "Deploy".
5. Pronto! Você ganha na hora um link como https://xennex-stream.pages.dev.
6. Cole esse link no Xennex no campo "Link Público Cloudflare Pages" na aba de Transmissão.
