# Dados públicos de distribuição

O empacotamento pode incluir `gestures.json`, `swipe_config.json` e
`team_config.txt` desta pasta. Adicione somente modelos públicos revisados.
Esses arquivos são opcionais; na ausência deles, os serviços usam seus padrões.

`Data/config.txt` é gerado pelo empacotador. A pasta pessoal `Data/` nunca é
usada como origem de uma release. Não copie tokens, builds ou configurações
pessoais para este diretório.
